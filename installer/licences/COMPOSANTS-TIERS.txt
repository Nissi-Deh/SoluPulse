SoluPulse - Composants tiers
============================

Pilote PawnIO
-------------
L'installeur de SoluPulse installe le pilote PawnIO, sans modification, pour lire
les capteurs de temperature et les ventilateurs.

  Auteur  : namazso
  Licence : GNU General Public License version 2 (texte complet : PawnIO-GPL-2.0.txt),
            avec une exception pour les programmes qui communiquent avec PawnIO
            par son interface IOCTL, comme SoluPulse.
  Sources : https://github.com/namazso/PawnIO
            https://github.com/namazso/PawnIO.Setup

PawnIO reste installe si SoluPulse est desinstalle, car d'autres logiciels
peuvent l'utiliser. Il se desinstalle depuis Parametres > Applications.

SoluPulse est un logiciel proprietaire de Solutech (tous droits reserves). Les
composants ci-dessous restent sous leur propre licence.
